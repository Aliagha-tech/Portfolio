📌 Overview

Welcome to the repository of my personal portfolio website. Designed and built from scratch with a minimalist aesthetic, fine typography, and dark-mode elegance to showcase my journey, skills, and background as a Frontend Developer.

"Crafting responsive, thoughtful web experiences. One year in — and genuinely passionate about the craft of the web."

🛠️ Tech Stack & Technologies

The portfolio is built purely with modern web technologies without heavy dependencies, focusing on performance, smooth animations, and clean code structure.

HTML5 — Semantic, clean, and accessible structure.

CSS3 — Custom properties (variables), Flexbox, CSS Grid, custom keyframe animations, and fully responsive layouts.

JavaScript (ES6+) — Lightweight dynamic interaction handling.

Typography — Google Fonts (Fraunces, Outfit, DM Mono).

💡 Core Features

🎨 Minimalist & Dark Design: Custom dark color scheme with subtle neon/pastel accents (#b8f0c8, #e8d5ff, #f5c07a).

📱 Fully Responsive: Optimized layout tailored for mobile, tablet, and desktop screens.

⚡ Performance Focused: Built using native CSS and HTML with zero heavy external libraries for fast load times.

✨ Smooth Animations: Subtle CSS keyframe animations (fadeUp) and state transitions on hover/interaction.
